---

## 🚀 Instrucciones de Reproducción

Sigue estos pasos para levantar la base de datos y replicar el entorno de trabajo:

1. **Creación de la base de datos:**
   * Abre **pgAdmin** y conéctate al servidor local.
   * En el panel lateral, haz clic derecho sobre `Databases` > `Create` > `Database...`.
   * Asigna el nombre `northwind` y confirma la creación.

2. **Carga del script SQL:**
   * Selecciona la base de datos `northwind` recién creada.
   * Abre la herramienta de consultas (`Query Tool` o `Tools > Query Tool`).
   * Abre el archivo de carga `northwind.sql` (o pega su contenido en el editor).
   * Ejecuta el script pulsando **Execute/Refresh (F5)** para poblar las tablas y datos.
